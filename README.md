# The Router Confesses

A one line excuse in a home Wi-Fi router's own voice for dropping the connection at the exact climax of a movie. The router is petty, dramatic and territorial: it cuts the film just as the killer is about to confess, because it refuses to let anyone out-confess it in its own house.
